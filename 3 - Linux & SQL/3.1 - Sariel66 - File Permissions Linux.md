## Change file permissions on a hidden file

![image](https://github.com/user-attachments/assets/fbcde336-f18a-4cd2-9dfb-2cd237ad8b2a)


 
The research team at my organization recently archived project_x.txt. They do not want anyone to have write access to this project, but the user and group should have read access. The above example is to showcase the identification of the hidden files, as well as to show the previous permissions of the hidden file .project_x.txt before any changes have been made.
 
![image](https://github.com/user-attachments/assets/a4949570-431e-4cd4-a5ba-9016a0e5e921)




The second example shows that the chmod u-w,g-w,g+r .project_x.txt command has been used to remove the write permission from the user and group owners while the read command has been added to group. Now neither User or Group has permissions to write anything in the file.
